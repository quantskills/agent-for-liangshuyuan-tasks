# plans/

`superpowers:writing-plans` 产出的实现计划放这里。

文件名：`YYYY-MM-DD-<feature>.md`，例如 `2026-09-09-leads-dedup.md`。

每份计划开头必须带上 skill 要求的 header（Goal / Architecture / Tech Stack / **Spec** / Global Constraints），
其中 `Spec` 指向 [`../specs/`](../specs/) 里对应的设计文档 —— 计划是围绕 spec 展开的，两者要一起走。

任务用 `- [ ]` checkbox 逐步跟踪；执行方式二选一：`superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`。

> 本工程的具体闸门（编译走 IDE、测试怎么跑、base 分支是 `develop`）见根目录 `../../../../AGENTS.md` 的「本工程的闸门替换」。
